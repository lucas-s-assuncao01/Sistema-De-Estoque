# 🛒 Mini Sistema de Estoque em Java (MVC + Arquivo)

Projeto desenvolvido em Java puro com foco em Programação Orientada a Objetos (POO), utilizando arquitetura MVC e persistência de dados em arquivo (.txt).

---

## 📌 Funcionalidades

- Cadastro de categorias
- Cadastro de itens com nome, preço e categoria
- Listagem de categorias
- Listagem de itens por categoria
- Busca de item por nome
- Remoção de item
- Validação para evitar itens ou categorias duplicadas
- Persistência de dados em arquivo `.txt`

---

## 🧠 Conceitos aplicados

- Programação Orientada a Objetos (POO)
- Encapsulamento
- Arquitetura MVC (Model, View, Controller)
- Manipulação de arquivos em Java
- Estrutura de dados com ArrayList
- Organização de código em camadas

---

## 📁 Estrutura do projeto

model → Classes de domínio (Item, Categoria, Mercado)
controller → Regras de negócio e persistência (BancoDeDados)
view → Interface via console (Menu)
Main → Inicialização do sistema

---

## 🚀 Como executar o projeto

1. Clonar o repositório
2. Abrir em uma IDE (IntelliJ, Eclipse ou VS Code)
3. Executar a classe `Main`
4. Utilizar o menu no console para interagir com o sistema
